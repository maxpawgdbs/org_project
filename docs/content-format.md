# Формат материалов для автора

Передайте один файл `content/route.json` в UTF-8 и файлы изображений в `content/photos/`. JSON должен быть валидным: двойные кавычки, без комментариев и запятой после последнего элемента. Текущий [файл маршрута](../content/route.json) показывает структуру всех полей: первая карточка взята из книги автора, остальные подготовлены на основе авторского плана.

| Поле маршрута | Что передать |
| --- | --- |
| `title` | Название маршрута |
| `introduction` | Краткое приветствие для `/start` |
| `audience` | Для кого маршрут |
| `duration` | Предполагаемая длительность текстом |
| `transport` | Список способов перемещения |
| `start_point`, `end_point` | Начальная и конечная точки текстом |
| `map_url` | Полная ссылка `https://…` на общую интерактивную карту |
| `map_image`, `map_note` | Необязательные путь к обзорному изображению и пояснение к нему |
| `final_text` | Итоговый текст после последней остановки |
| `authors` | Список авторов проекта |
| `stops` | Массив из 10 или более остановок |
| `quiz` | Ровно 5 вопросов |
| `is_placeholder` | `false` для заполненного маршрута |

У каждой остановки должны быть поля `id`, `order`, `title`, `address`, `latitude`, `longitude`, `photo`, `photo_credit`, `description`, `look_for`, `task`, `next_transition`, `sources`.

- `id` — уникальная стабильная строка. После публикации лучше её не менять, чтобы сохранённый прогресс указывал на ту же остановку.
- `order` — целое число от 1 до количества остановок без пропусков. Сортировка выполняется автоматически.
- `latitude` и `longitude` — числовые координаты точки, например `55.75` и `37.61`. Бот создаёт ссылку на Google Maps. В финальном маршруте координаты обязательны.
- `photo` — относительный путь, например `photos/01.jpg`; `photo_url` — необязательная прямая ссылка на изображение, если локальный файл недоступен; `photo_credit` — автор фото или указание лицензии текстом.
- `map_point_url` — необязательная авторская ссылка на карту точки. Если поле пусто, бот создаёт ссылку по координатам.
- `description` и `look_for` — полные тексты. Бот отправляет фотографию отдельно, а длинные тексты делит на несколько сообщений.
- `task` — вопрос/задание; если автор его не предусмотрел, пустая строка `""`.
- `task_answer` и `task_explanation` — необязательные ответ и пояснение, которые показываются отдельной кнопкой.
- `visit_info` — необязательные условия и место осмотра.
- `next_transition` — инструкция до следующей точки; у последней остановки может быть `""`.
- `sources` — массив объектов вида `{"title":"Название источника","url":"https://example.org/page"}`. В финальном маршруте нужен хотя бы один источник на остановку.

Каждый элемент `quiz` имеет `question` (текст), `options` (от 2 до 8 вариантов), `correct_index` (номер верного варианта **с нуля**) и `explanation` (короткое пояснение). Например, у трёх вариантов индекс `0` означает первый, `1` — второй.

Фотографии должны быть пригодны для отправки через Telegram как фото. Проверьте права использования и подписи. Программист не подбирает объекты, тексты и изображения и не проверяет исторические утверждения.

Перед передачей выполните `python -m scripts.validate_content content/route.json`.
